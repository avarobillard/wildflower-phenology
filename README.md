# Lady Bird Johnson Wildflower Center phenology

Exploration of a provided dataset of plants in bloom at the Wildflower Center from 2011 to 2026, a list of 1-24 plants per week (or per month) compiled by volunteers. Focusing on identifying any phenological changes that occurred over time and throughout seasons.
